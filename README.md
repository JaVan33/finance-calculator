# Finance Calculator
Finance Calculator je program určený k rychlému propočítání půjčky, převodu měn, výpočtu důchodu, inflace, rozpočtu, jmění, rezervy, DPH a marže a čisté mzdy.
V současnosti probíhá vývoj aplikace a v nejbližší době by měla vyjít první verze pro macOS.

_Programování aplikace probíhá za pomoci nástroje Google Gemini (AI model)._
